SmartShop

Política de Privacidade

Última atualização: 16 de agosto de 2026

Esta Política de Privacidade descreve como o SmartShop coleta, usa e protege seus dados pessoais. Ao usar o aplicativo, você concorda com as práticas descritas aqui.

1 Quem somos

O SmartShop é um aplicativo de gestão de listas de compra doméstica desenvolvido por Felipe Augusto Moreira da Silva. Para fins desta política, o desenvolvedor é o controlador dos dados pessoais coletados pelo aplicativo, conforme a Lei Geral de Proteção de Dados (Lei nº 13.709/2018 — LGPD).

2 Dados que coletamos

Dados de conta

  • Nome completo — fornecido no cadastro, exibido para outros membros da sua casa
  • Endereço de e-mail — usado para autenticação e recuperação de senha
  • Telefone — opcional, não obrigatório para usar o aplicativo

Dados de uso

  • Listas de compra e seus itens (nome do produto, quantidade, unidade, observações)
  • Catálogo de produtos da casa
  • Informações de pertencimento a casas (papel: dono ou convidado, status de aprovação)

Dados técnicos

  • Token de notificação push — gerado pelo sistema operacional, usado para enviar notificações sobre atividade no app; armazenado por dispositivo e removido automaticamente quando inválido

3 Como usamos seus dados

Seus dados são usados exclusivamente para:

  • Autenticar você no aplicativo e manter sua sessão ativa
  • Criar e gerenciar listas de compra colaborativas entre membros da mesma casa
  • Enviar notificações push sobre atividade relevante (novo membro solicitando entrada, lista de compra solicitada, item comprado)
  • Recuperar sua senha por e-mail quando solicitado

Não usamos seus dados para publicidade, venda a terceiros ou qualquer finalidade não descrita acima.

4 Compartilhamento de dados

Não vendemos seus dados pessoais. Compartilhamos apenas com os prestadores de serviço essenciais para o funcionamento do app:

Serviço Finalidade Política
Google Firebase Banco de dados (Firestore) e autenticação policies.google.com
Expo Infraestrutura de notificações push expo.dev/privacy
Apple APNs Entrega de notificações push (iOS) apple.com/legal/privacy
Google FCM Entrega de notificações push (Android) policies.google.com

5 Armazenamento e retenção

Seus dados são armazenados nos servidores do Firebase (Google), com sede nos EUA. O Firebase é certificado por padrões internacionais de segurança (ISO 27001, SOC 2/3).

Mantemos seus dados enquanto sua conta estiver ativa. Se você solicitar a exclusão da conta, removeremos seus dados em até 30 dias, salvo onde a retenção for exigida por lei.

6 Seus direitos (LGPD)

Como titular de dados pessoais, você tem os seguintes direitos garantidos pela LGPD:

AcessoVer os dados que temos sobre você
CorreçãoCorrigir dados incompletos ou incorretos
ExclusãoSolicitar a remoção dos seus dados
PortabilidadeReceber seus dados em formato legível
OposiçãoOpor-se a determinados tratamentos
InformaçãoSaber com quem compartilhamos seus dados

Para exercer qualquer desses direitos, entre em contato pelo e-mail indicado na seção 10.

7 Segurança

Adotamos medidas técnicas para proteger seus dados, incluindo:

  • Autenticação segura via Firebase Authentication (e-mail verificado)
  • Regras de acesso ao banco de dados que garantem que cada usuário acessa apenas os dados das casas de que faz parte
  • Transmissão de dados via HTTPS/TLS em todos os pontos

Nenhum sistema é 100% seguro. Em caso de incidente que afete seus dados, notificaremos os titulares e a autoridade competente conforme exigido pela LGPD.

8 Menores de idade

O SmartShop não é direcionado a menores de 13 anos e não coleta conscientemente dados de crianças. Se você acreditar que coletamos dados de um menor, entre em contato para que possamos removê-los imediatamente.

9 Alterações nesta política

Podemos atualizar esta política periodicamente. Quando houver alterações relevantes, notificaremos os usuários pelo e-mail cadastrado ou por aviso dentro do aplicativo, com pelo menos 15 dias de antecedência. A data de "última atualização" no topo deste documento é sempre revisada a cada alteração.
